# چک‌لیست صفحه‌ساز — صفحه‌های محتوایی (گام ۲۱)

این سند «چه چیزی باید درست باشد» و «چه چیزی الان درست است» را کنار هم می‌گذارد.
هر ردیف یا با تست خودکار پوشش دارد (مسیر اجرایش را هم می‌نویسد) یا بازدید دستی است.

اجرا:
```bash
node infrastructure/verify-page-builder.mjs                     # بررسی ایستای مرزها (بدون DB)
pnpm --filter @ghasedak/api test -- phase21 phase17 phase22     # تست‌های منطق صفحه‌ساز + ناوبری
pnpm --filter @ghasedak/admin test                              # فرم ویرایش بخش‌ها (رفت‌وبرگشتِ متن)
node apps/storefront/scripts/verify-content-pages.mjs           # بررسی زندهٔ ۶ مسیر (API+سایت روشن)
node .run-local/verify-content-nav.mjs                          # ناوبریِ قابل‌ویرایش با مرورگر واقعی (نام/ترتیب/پنهان‌سازی)
```

## ج) تصمیم‌های این گام (برای رجوعِ آینده)

1. **صفحهٔ محتوایی = یک بلوک `CONTENT_PAGE`**، نه هیرو + متن‌ها. چون این صفحه‌ها در
   سایت هیرو ندارند و «صفحهٔ پنل باید عین سایت باشد» شکایتِ اصلی بود.
2. **ذخیرهٔ متنِ بخش، نشانه‌گذاریِ کم است** (`site-content/markup.ts`): هر خط یک بند؛
   `- ` فهرست؛ `> ` یادداشت؛ `[متن](پیوند)` پیوند؛ `**متن**` برجسته. جفت‌وشیِ دقیق
   دارد و تستِ رفت‌وبرگشت می‌گیرد.
3. **فهرست‌ها از یک جا می‌آیند**: پیشنهادیِ پنل از `SITE_EDITABLE_PAGES` مشتق است؛
   عنوانِ مسیرها از `LEGAL_PAGE_TITLES`. دیگر «فهرستی که از واقعیت جا می‌ماند» نداریم.
4. **بدون انتشار خودکار**: مهاجرت پیش‌نویس می‌سازد؛ انتشار یک کلیکِ دستیِ مدیر است.
5. **مدلِ ذخیره همان نشانه‌گذاری می‌ماند**: ویرایشگرِ ساختاریافته فقط **نمای** دیگری
   از همان `body` است. اگر بعداً فرم دیگری بخواهیم، نه API و نه دادهٔ ذخیره‌شده عوض
   نمی‌شود — فقط تبدیل در `apps/admin/lib/content-sections.ts`.6. **نشانه با موقعیت می‌شناسد، با عبارت نه**: عبارت می‌تواند در یک جمله دوبار بیاید و فقط یکی‌اش پیوند باشد (صفحهٔ تماس همین است). پس هر نشانه `at` دارد و هنگامِ ویرایشِ متن جابه‌جا می‌شود.
7. **ناوبری از `Setting` می‌آید** (`cms.contentNav`)، نه از کد و نه از هر صفحه: نوار بین شش صفحه مشترک است و باید همیشه یکی باشد. `href` هر گزینه از `CONTENT_PAGE_NAV` می‌آید تا مدیر نتواند پیوند بسازد؛ خواندنِ ذخیره **دفاعی** است (مقدارِ خراب نوار را خالی نمی‌کند) و نوشتن **سخت‌گیرانه** (خطا به چشم مدیر). «حذف» = `visible: false`؛ صفحه هست و از آدرس باز می‌شود، فقط از نوار پیوندش نیست.
