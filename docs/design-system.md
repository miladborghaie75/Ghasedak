# سند طراحی — لباس زیر قاصدک

> تثبیت هویت بصری (بند F1-13). این سند «منبع حقیقت» توکن‌ها و قوانین است؛
>globals.css هر دو اپ نقطهٔ اجرایی توکن‌هاست و این سند چرایی و روش استفاده را می‌سازد.

## اصل حاکم

هویت: **خاک‌رس بنفش (clay) کنترل‌شده** — گردی نرم، سایه‌های سه‌سطحی، بنفش گرم روی زمینهٔ روشنِ بنفش‌فام.
تمایز از قالب‌های پیش‌فرض: پالت از خود برند پین شده، نه از Tailwind؛ هیچ رنگ خام در کامپوننت‌ها نیست؛
لایهٔ معنایی (--app-*) بین توکن و مصرف‌کننده است تا تم شب بازنگری شود بدون دست‌زدن به کد.

## پالت (تم روز)

| توکن | مقدار | نقش |
|---|---|---|
| bg | `#fbf8fe` | زمینهٔ صفحه — بنفش‌فام، نه سفید خالص |
| surface | `#ffffff` | کارت‌ها و پنل‌ها |
| ink / muted | `#29232f` / `#756a7b` | متن اصلی / متن ثانویه |
| line | `#e3dce8` | خطوط و حاشیه‌ها |
| plum | `#3b2948` | بنفش تیرهٔ برند — تیترها |
| primary | `#8a5bc9` | اکشن اصلی (hover `#7a4ab8`، press `#5a379c`) |
| primary-light/tint/soft | `#eee6f8` / `#f6f1fc` / `#d9c8f2` | سه سطح روشنیِ پشتیبان primary |
| sage / dusty-rose | `#8fa89b` / `#c9829d` | لهجه‌های فرعی — فقط تزئین محدود |
| success / error | `#3f8a68` / `#c94a5a` | بازخورد وضعیت |

## تم شب

همهٔ توکن‌های معنایی بازتعریف می‌شوند (`[data-theme="dark"]`) — بنفش روشن‌تر روی زمینهٔ بنفش-تیره
(مثل `--app-primary: #c3a4f2` روی `#221b2c`). کنتراست WCAG حفظ شده؛ فیلتر/وارونگی ممنوع.

## تایپوگرافی

- **بدنه: Vazirmatn Variable** — همهٔ متن‌ها؛ اعداد قیمت با `.tnum` (tabular-nums).
- **تیترها: Lalezar** — فقط تیترهای نمایشی (کلاس `font-display`)؛ لاله‌زار شخصیت برند را حمل می‌کند.
- مقیاس: تیتر صفحه `text-3xl`، تیتر بخش `text-lg/xl`، بدنه `text-sm/[13px]`، ریزمتن `text-xs/[11-12px]`.
- اعداد فارسی همه‌جا با `faNum()`؛ قیمت‌ها همیشه با «تومان».

## شکل و سایه (clay)

- شعاع‌ها: `--radius-card: 1.25rem` (کارت)، `--radius-blob: 1.75rem` (سطوح بزرگتر/هیرو). دکمه‌ها گرد کامل.
- سایه: فقط **سه سطح** `shadow-clay-1/2/3` — سایه بنفش‌فام، نه خاکستری. سایهٔ سطح چهارم ممنوع.
- عمق با پس‌زمینهٔ tint + سایه ساخته می‌شود، نه با border ضخیم.

## موشن (محدود)

- **یک لحظهٔ شاخص:** ریویل ملایم بلوک‌های لندینگ (`data-motion=reveal`) — شدت/خاموشی از تنظیمات ادمین.
- ورود شیت: `sheet-up` ۰٫۲۸ث؛ پالس پین هیرو فقط موبایل.
- همیشه: `prefers-reduced-motion` → همهٔ موشن‌ها خاموش. هاور فقط تغییر رنگ/سایه، نه جابه‌جایی عناصر پرتکرار.

## قوانین سخت

1. هیچ رنگ hex خام در کامپوننت‌ها — فقط توکن (استثنا: OG-کارت و icon.svg که خارج از CSS زنده‌اند).
2. **عکس مدل زن استفاده نمی‌شود** (قانون برند) — تا رسیدن عکس واقعی محصول، آرت SVG (ProductArt) جایگزین است.
3. متن‌های لاتین/شماره/SKU/تلفن → `dir="ltr"`؛ بقیه صفحه RTL است.
4. حالت خالی = دعوت به اقدام (CTA روشن)؛ خطا = توضیح راه‌حل، نه عذرخواهی؛ بارگذاری = اسکلتون هم‌شکل محتوا.
5. فوکوس کیبورد: `outline 3px primary-strong` — هرگز حذف نمی‌شود.
