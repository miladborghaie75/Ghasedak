# شات‌لیست عکاسی واقعی محصول (بند F1-13)

> پذیرش گام ۹ «صفحات لانچ بدون تصویر جانشین» فقط با عکس واقعی محصول بسته می‌شود.
> تا آن موقع آرت SVG (ProductArt) جایگزین است. این سند دستور عکاسی و جای عکس‌هاست.

## قانون برند (بند ۵)

هیچ عکس مدل زن استفاده نمی‌شود. سبک: **flat-lay / فرم‌نمایش بی‌مانکن** روی سطح روشن.
دست/بند تن در کادر مجاز نیست. کالا باید «همان چیزی که می‌رسد» را نشان دهد — پلمب، برچسب سایز و رنگ واقعی.

## راه‌اندازی ثابت همهٔ شات‌ها

- پس‌زمینه: سفید مات یا `#f6f1fc` (tint برند)؛ بدون بافت و سایهٔ تند.
- نور: یک سافت‌باکس ۴۵ درجه + رفلکتور؛ بدون فلاش مستقیم (پارچه شفاف دچار سوختگی نور نمی‌شود).
- دوربین: عمود بر سطح (top-down) برای flat-lay؛ سه‌رخ (۳۰°) فقط برای ست‌ها.
- خروجی: JPG/WebP، **۱۲۰۰×۱۲۰۰ مربع**، کیفیت ۸۰+؛ نام فایل: `p-<slug>.jpg`.

## شات‌لیست پایه (به ازای هر محصول عرضه‌شده)

| # | کادر | توضیح |
|---|---|---|
| ۱ | flat-lay جلو | کالا صاف، برچسب سایز خوانا؛ «عکس اصلی» کارت و PDP |
| ۲ | flat-lay پشت | دوخت و بند پشت |
| ۳ | نمای رنگ‌ها | واریانت‌های رنگی کنار هم (اگر >۱ رنگ) |
| ۴ | جزئیات پارچه | بافت/کش‌باف از نزدیک، بدون ماکروی افراطی |
| ۵ | حالت فرم | کالا ایستاده/شکل واقعی (فقط گن و ست) |

عکس اصلی (۱) اجباری است؛ ۲–۵ به ترتیب اولویت.

## اولویت عکاسی (به ترتیب فروش)

۱. سوتین‌های پرفروش (bra) — همهٔ رنگ‌های اصلی
۲. ست‌ها (set)
۳. گن (shapewear) — نمای فرم مهم است
۴. شورت (panty) و لباس خواب/ورزشی
۵. هیرو جایگزین: بازسازی `hero-drawer.jpg` با محصولات واقعی داخل کشو (همان ترکیب فعلی)

## جای عکس و جایگزینی

1. عکس‌ها را از **پنل ادمین → رسانه** آپلود کنید (ذخیره در object storage، سرو از `/media/<key>`).
2. در ویرایش محصول، عکس را به‌عنوان **عکس اصلی** ثبت کنید (فیلد image).
3. فروشگاه خودکار عکس واقعی را جای ProductArt نشان می‌دهد — نه تغییری در کد لازم است، نه دیپلوی.
4. بعد از ثبت عکس، PDP و کارت را باز کنید و رندر مربع بودن/کیفیت را چک کنید.

## چک‌لیست نهایی عکس

- [ ] همهٔ محصولات «عرضه‌شده» (PUBLISHED با موجودی) عکس اصلی دارند
- [ ] رنگ عکس با نام واریانت یکی است (شورتِ «سرمه‌ای» ≠ عکس صورتی)
- [ ] عکس‌های هیرو/بنر لندینگ واقعی شده‌اند (hero-drawer بازسازی شود)
- [ ] آلت هر عکس = نام محصول (در پنل رسانه پر شود)
